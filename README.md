# Drika's Forminhas

## Descrição do Projeto

O projeto consiste no desenvolvimento de um site para a **Drika's Forminhas**, um pequeno negócio familiar especializado na produção e venda de forminhas para festas.

O site terá como objetivo divulgar os produtos, apresentar informações sobre o negócio e facilitar o contato com os clientes, contribuindo para ampliar sua presença e divulgação no ambiente digital.
